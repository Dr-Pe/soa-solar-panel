# Proyecto Sunflower
Sistema de seguimiento solar automatizado diseñado con el objetivo de mejorar
la eficiencia en la captación de luz solar y promover el uso de energías
renovables. El sistema utiliza sensores lumínicos, servomotores y una placa
Arduino UNO. Cuenta con una aplicación móvil para control y obtención de
estadisticas del dispositivo.
\
**Palabras claves:** energía, solar, eficiencia, renovable, mobile.
